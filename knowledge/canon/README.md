# Каноны: как устроены и что в них есть

Три раздела: **персонажи**, **локации**, **события**. Источник истины — файлы
`../screenplay/epNN.md`; каноны — их срез по сущностям. Если карточка расходится
со сценарием, прав сценарий.

## Состав

| Раздел | Что там |
|---|---|
| [`characters/`](characters/) | **151 карточка.** Игровые персонажи, ключевые НИП, эпизодические фигуры |
| [`locations/`](locations/) | **26 карточек.** Города, здания, острова, леса — с планировкой, где она известна |
| [`items/`](items/) | Предметы, которые двигают сюжет: чьи, откуда взялись, что с ними происходило. Раздел заведён 30.07.2026, наполняется по мере прохода серий |
| [`events/`](events/) | **55 файлов, 2051 событие.** По одному файлу на серию |

## Идентификаторы событий

`N.M` — номер эпизода и номер события внутри него: `2.17` это семнадцатое
событие второй серии. На эти id ссылаются карточки персонажей и локаций.

Таблицы событий собраны из блоков «Итог» соответствующих сцен сценария, поэтому
у каждого события есть таймкод, и любое утверждение проверяется открытием записи
на этой минуте.

## Связи между карточками

Внутри канонов работают вики-ссылки вида `[[publiy]]` — по имени файла без
расширения. Их около 6500, и они связывают персонажей, места и события в единую
сеть: из карточки локации видно, кто там был, из карточки персонажа — где он
побывал и в каких событиях участвовал.

## Правила

- Каждый факт — со ссылкой на таймкод или на id события
- Чего в записи нет, того нет в каноне; догадка помечается `[?]`
- Спорные написания — по [`../GLOSSARY.md`](../GLOSSARY.md)
- Что осталось невыясненным — [`../OPEN_QUESTIONS.md`](../OPEN_QUESTIONS.md)

## Как проверить

```bash
python3 tech/scripts/audit_npc.py       # у всех ли говорящих есть карточка
python3 tech/scripts/audit_corpus.py    # в том числе битые вики-ссылки
```

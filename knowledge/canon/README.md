# Каноны: как устроены и что в них есть

Четыре раздела: **персонажи**, **локации**, **предметы**, **события**. Источник
истины — файлы `../screenplay/epNN.md`; каноны — их срез по сущностям. Если
карточка расходится со сценарием, прав сценарий.

## Состав

| Раздел | Что там |
|---|---|
| [`characters/`](characters/) | **167 карточек.** Игровые персонажи, ключевые НИП, эпизодические фигуры |
| [`locations/`](locations/) | **72 карточки.** Города, здания, острова, леса — с планировкой, где она известна |
| [`items/`](items/) | **26 карточек.** Предметы, которые двигают сюжет: чьи, откуда взялись, что с ними происходило |
| [`events/`](events/) | **55 файлов, по одному на серию.** Хронология событий с таймкодами |

## Идентификаторы событий

`N.M` — номер эпизода и номер события внутри него: `2.17` это семнадцатое
событие второй серии. На эти id ссылаются карточки персонажей и локаций.

Таблицы событий собраны из блоков «Итог» соответствующих сцен сценария, поэтому
у каждого события есть таймкод, и любое утверждение проверяется открытием записи
на этой минуте.

## Связи между карточками

Внутри канонов работают **обычные markdown-ссылки с относительным путём**: из карточки
персонажа на соседнюю — `publiy.md`, на локацию — `../locations/hramorra.md`. Формат `[[slug]]`
не используется: это синтаксис Obsidian, в обычном просмотре markdown он не
работает. Ссылка ставится **на первое упоминание внутри раздела**, дальше в этом
же разделе просто имя. Связывают они
персонажей, места и события в единую сеть: из карточки локации видно, кто там
был, из карточки персонажа — где он побывал и в каких событиях участвовал.

## Правила

- Каждый факт — со ссылкой на таймкод или на id события
- Чего в записи нет, того нет в каноне; догадка помечается `[?]`
- Имена — по [`../NAMES_CANON.md`](../NAMES_CANON.md), список шоураннера; всё
  остальное спорное — по [`../GLOSSARY.md`](../GLOSSARY.md)
- Что осталось невыясненным — [`../OPEN_QUESTIONS.md`](../OPEN_QUESTIONS.md)

## Как проверить

Открыть серию на таймкоде события и посмотреть. Всё остальное — вспомогательное:
ссылки и счётчики можно прогнать проверкой, но она ловит только то, про что её
научили спрашивать. Расхождение карточки с записью так не находится.
